# LeetCode Black & Light

VS Code color themes inspired by LeetCode, with no blue status bar.

- **LeetCode Dark (no blue bar)** – neutral dark gray, status bar blends into the editor.
- **LeetCode Light** – light variant, same status bar treatment.

## Install

Copy this folder to `~/.vscode/extensions/ksawery.leetcode-black-0.0.1`, reload VS Code, then pick the theme with `Cmd+K Cmd+T`.
